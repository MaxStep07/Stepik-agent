## 🧠 Как это работает

В отличие от медленных и хрупких браузерных ботов (Selenium / Playwright), **Stepik Agent** общается напрямую со **Stepik REST API** и использует языковые модели (LLM) со строгой валидацией ответов через **Pydantic (Structured Outputs)**.

```text
┌───────────────────┐     1. Загрузка дерева курса     ┌────────────────────┐
│   Stepik Agent    │ ───────────────────────────────► │  Stepik REST API   │
│    (Python CLI)   │ ◄─────────────────────────────── │ (sections → steps) │
└─────────┬─────────┘     2. Фильтрация нерешённых     └─────────▲──────────┘
          │                                                      │
          │ 3. HTML → Markdown + сбор теории урока               │ 6. Отправка reply
          ▼                                                      │    и поллинг грейдера
┌───────────────────┐     4. Промпт + JSON-схема       ┌─────────┴──────────┐
│  Context Builder  │ ───────────────────────────────► │    LLM Solver      │
│  & Step Handlers  │ ◄─────────────────────────────── │ (Groq/Gemini/etc.) │
└───────────────────┘     5. Валидный JSON-ответ       └─────────▲──────────┘
                                                                 │
                     7. Если статус "wrong" — передаём           │
                        подсказку грейдера (hint) обратно ───────┘
                        (цикл самоисправления до N попыток)
```

### Ключевые особенности
- **Понимание контекста урока:** агент очищает HTML-условия в компактный Markdown и накапливает всю теорию предыдущих шагов текущего урока (даже уже пройденных), чтобы тесты и задачи опирались на формулировки конкретного автора.
- **Цикл самоисправления (Self-Correction):** если грейдер Stepik отклоняет решение (`wrong`), агент забирает текст ошибки/подсказки (`hint`), отправляет его обратно в LLM и пробует исправить код или ответ (до `MAX_ATTEMPTS_PER_STEP` попыток).
- **Гибкость LLM и резервирование (Fallback):** поддерживаются **Gemini API** и любые **OpenAI-совместимые провайдеры** (Groq, OpenRouter, DeepSeek, локальный Ollama). При перегрузке или лимитах (`429`/`503`) агент автоматически переключается на запасные модели из списка `FALLBACK_MODELS`.
- **Вежливая работа с API:** встроенные случайные паузы между запросами и экспоненциальные повторы при временных сбоях сети.
- **Отчет по сложным шагам:** если задача не решилась за лимит попыток или требует ручной проверки преподавателем, агент не останавливается, а записывает прямую ссылку на шаг в файл `skipped_steps.md`.

## 📋 Поддерживаемые типы заданий

| Категория | Тип шага (`block.name`) | Как обрабатывает агент |
| :--- | :--- | :--- |
| **Теория** | `text`, `video` | Добавляет текст в контекст урока и отмечает шаг просмотренным |
| **Код и БД** | `code`, `sql` | Учитывает язык, стартовый шаблон редактора и примеры тестов |
| **Тесты** | `choice` | Одиночный и множественный выбор вариантов |
| **Ввод ответа** | `string`, `number`, `math` | Краткий текстовый, числовой ответ и математические формулы |
| **Структурные** | `sorting`, `matching` | Расстановка элементов по порядку и сопоставление пар |
| **Интерактивные** | `fill-blanks`, `table` | Заполнение пропусков в тексте и выбор ячеек таблиц |
| **Прочие** | `free-answer` и др. | Пропускает и добавляет прямую ссылку в `skipped_steps.md` |

## 💻 Установка (пошагово для новичков)

### Шаг 1. Установите Python
Для работы агента нужен **Python 3.10 или новее**.
1. Скачайте установщик с официального сайта: [python.org/downloads](https://www.python.org/downloads/).
2. **Важно для Windows:** на самом первом экране установщика обязательно поставьте галочку **«Add python.exe to PATH»** (внизу окна), затем нажмите **Install Now**.
3. Проверьте установку — откройте терминал (в Windows: нажмите `Win + R`, введите `powershell` и нажмите `Enter`) и выполните:
   ```bash
   python --version
   ```
   Вы должны увидеть версию вида `Python 3.11.x` или выше.

---

### Шаг 2. Скачайте проект на компьютер

Выберите любой удобный способ:

- **Способ А — скачать архивом (самый простой, без Git):**
  1. На странице этого репозитория на GitHub нажмите зеленую кнопку **`<> Code`** → **`Download ZIP`**.
  2. Распакуйте архив в удобную папку (желательно без русских букв и пробелов в пути, например `C:\stepik-agent`).
  3. Откройте эту папку в терминале (в Windows: откройте папку в Проводнике, кликните на адресную строку сверху, введите `powershell` и нажмите `Enter`).

- **Способ Б — через Git:**
  ```bash
  git clone https://github.com/MaxStep07/Stepik-agent.git
  cd Stepik-agent
  ```

---

### Шаг 3. Создайте виртуальное окружение и установите библиотеки

Выполните команды по очереди в терминале внутри папки проекта:

1. **Создайте изолированное окружение `.venv`:**
   ```bash
   python -m venv .venv
   ```

2. **Активируйте окружение:**
   - **Windows (PowerShell):**
     ```powershell
     .venv\Scripts\Activate.ps1
     ```
     > [!TIP]
     > Если PowerShell выдал красную ошибку про запрет выполнения скриптов (`ExecutionPolicy`), выполните один раз команду `Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser`, подтвердите буквой `Y` и повторите активацию.
   - **Windows (CMD / командная строка):**
     ```cmd
     .venv\Scripts\activate.bat
     ```
   - **macOS / Linux:**
     ```bash
     source .venv/bin/activate
     ```
   *Успех:* в начале строки терминала появится префикс `(.venv)`.

3. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

## 🔧 Настройка: откуда что брать и куда вставлять

Все личные ключи и настройки хранятся в локальном файле `.env` в корне проекта (он добавлен в `.gitignore` и никогда не попадет в интернет).

### Шаг 1. Создайте файл `.env`
Скопируйте шаблон `.env.example` и назовите копию `.env`:
- **В Windows (PowerShell):**
  ```powershell
  Copy-Item .env.example .env
  ```
- **В macOS / Linux:**
  ```bash
  cp .env.example .env
  ```
*(Либо просто скопируйте и переименуйте файл вручную в Проводнике / VS Code. Убедитесь, что файл называется именно `.env`, а не `.env.txt`!)*

Теперь откройте `.env` в любом текстовом редакторе (Блокнот, VS Code) и заполните три блока ниже.

---

### Шаг 2. Получите API-ключ нейросети (LLM)

Агент умеет работать с разными сервисами. Ниже приведены два самых удобных варианта с бесплатным доступом.

#### Вариант 1: Groq (рекомендуется — бесплатно и очень быстро)
1. Перейдите на [console.groq.com](https://console.groq.com/) и войдите через Google или GitHub.
2. В левом меню выберите **API Keys** → нажмите **Create API Key**.
3. Введите любое название (например, `stepik-agent`), в поле Expiration выберите *No expiration* (или 30/90 дней) и нажмите **Submit**.
4. **Сразу скопируйте ключ** (начинается с `gsk_...`) — он показывается только один раз.
5. Вставьте в `.env`:
   ```env
   LLM_PROVIDER=openai
   OPENAI_API_KEY=gsk_ваш_скопированный_ключ
   OPENAI_BASE_URL=https://api.groq.com/openai/v1
   OPENAI_MODEL=openai/gpt-oss-120b
   OPENAI_FALLBACK_MODELS=qwen/qwen3.8-27b,openai/gpt-oss-20b
   ```

#### Вариант 2: OpenRouter (агрегатор с бесплатными `:free` моделями)
1. Зарегистрируйтесь на [openrouter.ai](https://openrouter.ai/), откройте **Keys** → **Create Key**.
2. Вставьте в `.env`:
   ```env
   LLM_PROVIDER=openai
   OPENAI_API_KEY=sk-or-v1-ваш_ключ
   OPENAI_BASE_URL=https://openrouter.ai/api/v1
   OPENAI_MODEL=openrouter/free
   OPENAI_FALLBACK_MODELS=
   ```

#### Вариант 3: Google Gemini API
1. Перейдите в [Google AI Studio (API Keys)](https://aistudio.google.com/apikey) и нажмите **Create API key**.
2. Вставьте в `.env`:
   ```env
   LLM_PROVIDER=gemini
   GEMINI_API_KEY=AIzaSy_ваш_ключ
   GEMINI_MODEL=gemini-3.8-flash
   GEMINI_FALLBACK_MODELS=gemini-3.7-flash,gemini-3.6-flash
   ```
*(Аналогично через `LLM_PROVIDER=openai` можно подключить DeepSeek, OpenAI или локальный Ollama — достаточно указать нужный `OPENAI_BASE_URL` и имя модели.)*

---

### Шаг 3. Получите Cookies авторизации Stepik (`sessionid` и `csrftoken`)

Агент использует вашу текущую сессию браузера — пароль от аккаунта вводить никуда не нужно.

1. Откройте [stepik.org](https://stepik.org/) в браузере и убедитесь, что вы вошли в свой аккаунт.
2. Нажмите клавишу **`F12`** (или нажмите правой кнопкой мыши в любом месте страницы → **Просмотреть код / Inspect**).
3. В открывшейся панели разработчика перейдите на вкладку:
   - **Chrome / Edge / Яндекс Браузер / Opera:** вкладка **Application** (Приложение) — если её не видно, нажмите на стрелочки `>>` в верхней панели DevTools.
   - **Firefox:** вкладка **Storage** (Хранилище).
4. В левом меню раскройте пункт **Cookies** и кликните по строке **`https://stepik.org`**.
5. В таблице найдите две строки и скопируйте их значения из столбца **Value**:
   - `sessionid` → вставьте в `STEPIK_SESSION_ID=...`
   - `csrftoken` → вставьте в `STEPIK_CSRF_TOKEN=...`

> [!IMPORTANT]
> Никому не передавайте ваш `sessionid` — он дает полный доступ к аккаунту Stepik. В `.env` вставляйте значения без кавычек и без лишних пробелов вокруг знака `=`.

---

### Шаг 4. Укажите ID нужного курса (`STEPIK_COURSE_ID`)

1. Откройте нужный курс на Stepik и убедитесь, что вы уже нажали кнопку **«Поступить на курс»**.
2. Посмотрите на ссылку в адресной строке браузера:
   ```text
   https://stepik.org/course/77/syllabus
                             ▲▲
                        это ID курса
   ```
3. Впишите это число в `.env`:
   ```env
   STEPIK_COURSE_ID=77
   ```

### Сводка всех параметров `.env`

| Параметр | Обязательно | Описание и пример |
| :--- | :---: | :--- |
| `LLM_PROVIDER` | Да | `openai` (для Groq, OpenRouter, DeepSeek, Ollama) или `gemini` |
| `OPENAI_API_KEY` | Если `openai` | API-ключ вашего OpenAI-совместимого провайдера |
| `OPENAI_BASE_URL` | Если `openai` | Базовый URL API (например, `https://api.groq.com/openai/v1`) |
| `OPENAI_MODEL` | Если `openai` | Основная модель (например, `openai/gpt-oss-120b`) |
| `OPENAI_FALLBACK_MODELS` | Нет | Резервные модели через запятую без пробелов |
| `GEMINI_API_KEY` | Если `gemini` | API-ключ из Google AI Studio |
| `GEMINI_MODEL` | Нет | Основная модель Gemini (по умолчанию `gemini-3.8-flash`) |
| `GEMINI_FALLBACK_MODELS` | Нет | Резервные модели Gemini через запятую |
| `STEPIK_SESSION_ID` | Да | Значение cookie `sessionid` с сайта stepik.org |
| `STEPIK_CSRF_TOKEN` | Да | Значение cookie `csrftoken` с сайта stepik.org |
| `STEPIK_COURSE_ID` | Да | Числовой ID курса из URL |
| `MAX_ATTEMPTS_PER_STEP` | Нет | Максимум попыток на один шаг (по умолчанию `4`) |
| `MIN_DELAY_SEC` / `MAX_DELAY_SEC` | Нет | Диапазон случайной паузы в секундах между шагами (`1.5`–`3.5`) |

## 🚀 Запуск и использование

Убедитесь, что виртуальное окружение `(.venv)` активно, и вы находитесь в папке проекта.

### 1. Тестовый запуск (рекомендуется в первый раз)
Чтобы проверить ключи, сессию и посмотреть на работу агента вживую, запустите его с ограничением на **5 ближайших нерешённых шагов**:
```bash
python main.py --limit 5
```

### 2. Полное прохождение курса
Если тестовый прогон прошёл успешно, запускайте без флага `--limit` — агент пройдёт все оставшиеся шаги до конца курса:
```bash
python main.py
```

### Полезно знать во время работы
- **Пауза и продолжение:** вы можете в любой момент остановить скрипт нажатием **`Ctrl + C`**. Весь прогресс сохраняется на сервере Stepik — при следующем запуске агент автоматически пропустит уже пройденные шаги и продолжит с места остановки.
- **Пропущенные задания:** если какие-то шаги не удалось решить за лимит попыток (или они требуют ручной проверки), в корне проекта автоматически появится файл **`skipped_steps.md`** — удобная таблица с причиной и прямыми кликабельными ссылками на каждый такой шаг.

## 🧰 Частые проблемы и их решение

<details>
<summary><b>Ошибка: «Сессия не авторизована (определен как гость)» или HTTP 401/403</b></summary>

Ваши cookies устарели (например, вы вышли из аккаунта в браузере) или были скопированы не полностью.
- Заново откройте `stepik.org`, обновите страницу, скопируйте свежие `sessionid` и `csrftoken` из DevTools (`F12`) и сохраните `.env`.
</details>

<details>
<summary><b>Ошибка: «Request URL is missing an 'http://' or 'https://' protocol»</b></summary>

Проверьте строку `OPENAI_BASE_URL` в `.env`: она обязательно должна начинаться с `https://` (например, `https://api.groq.com/openai/v1`), без кавычек, скобок и лишних символов.
</details>

<details>
<summary><b>Модель возвращает 404 (model_not_found), 429 (лимит) или 503 (перегрузка)</b></summary>

- **404:** провайдер переименовал или отключил модель. Проверьте список актуальных моделей в личном кабинете вашего провайдера и обновите `OPENAI_MODEL` / `GEMINI_MODEL`.
- **429 / 503:** временная перегрузка бесплатного тира или исчерпание лимита запросов в минуту. Добавьте запасные модели в `OPENAI_FALLBACK_MODELS` (через запятую) или переключитесь на другого провайдера (например, с Gemini на Groq или OpenRouter).
</details>

<details>
<summary><b>Терминал Windows «завис» и ничего не печатает</b></summary>

В Windows PowerShell включён режим быстрого выделения (QuickEdit): если случайно кликнуть мышкой внутри окна терминала и выделить кусочек текста, выполнение Python-скрипта ставится на паузу. Нажмите **`Esc`** или **`Enter`** в окне терминала — выполнение мгновенно продолжится.
</details>

<details>
<summary><b>Скрипт не видит изменений в .env</b></summary>

Убедитесь, что вы сохранили файл (`Ctrl + S`), он называется ровно `.env` (без `.txt` в конце), и в нём нет дублирующихся строк с одинаковым именем переменной (нижняя строка перезаписывает верхнюю).
</details>
